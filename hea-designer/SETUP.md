# HEA Designer v2 (제2안 · 연구 워크벤치) — 로컬 실행 가이드

제1안(`hea-designer`)과 나란히 비교하기 위한 제2안 프로토타입입니다.
"AI가 답을 주는 화면"이 아니라 "연구자가 설계 공간을 탐색하고 실험을 기록하는 도구"를 목표로 합니다.

## 실행

```bash
cd hea-designer-v2
npm install      # 최초 1회
npm run dev      # http://localhost:3001
```

- v2는 **3001번 포트**를 씁니다. 제1안(`hea-designer`, 3000번)과 동시에 띄워 두 탭에서 비교할 수 있습니다.
- 입력한 설계 조건·Run·시편·실측 결과·노트는 브라우저(localStorage)에 저장되어 새로고침해도 유지됩니다.
- 왼쪽 아래 "세션"에서 저장(JSON) · 불러오기 · 초기화를 할 수 있습니다. 상단 "+ 새 설계"는 이력은 두고 1단계부터 다시 시작합니다.
- 왼쪽 단계의 ✓ 표시는 지금 보고 있는 Run 기준입니다.

## 화면 구성

| 메뉴 | 내용 |
|---|---|
| 1 설계 조건 | 주기율표 전 원소(118종) 선택, 목표 물성, 연구 가설. 조성 범위·간격은 원소 수에 맞춰 자동 설정(고급 설정에서 직접 지정 가능) |
| 2 계산 | 원자가 결합해 BCC 격자가 되는 합성 애니메이션 + 실제 계산 로그 → 완료 후 탐색 공간으로 자동 이동 |
| 3 탐색 공간 | 우선 검토 조성 3개(서로 다른 조성), 강도–연성 / 상 형성 맵 탭 그래프, 선택 조성 상세 패널, 조성 목록 |
| 4 시편 후보 | 시편 목록 + 상세(조성 조정·예측·descriptor·점검·공정), 비교표 탭 |
| 5 실험 계획서 | 배치 질량 기준 칭량표(at% → wt% → g), 공정 조건, 분석 계획 — 인쇄/PDF |
| 6 실측 결과 | 상(XRD)·YS·EL·경도 입력 → 예측–실측 비교 그래프, 오차 |
| 문헌 데이터 | 비교 기준 문헌값 검색·필터 |
| 연구 노트 | 계산·등록·상태 변경·실측 입력 자동 기록 + 메모, Markdown 내보내기 |

## 제1안과 달라진 점 (요약)

- **계산이 실제로 돈다**: VEC, δ, ΔHmix(Miedema 이원계 값), ΔSmix, Ω, Tm, 밀도를 조성에서 직접 계산합니다.
  설계 조건의 at% 범위·필수 포함·밀도 상한이 모두 결과에 반영됩니다.
- **답 3개 대신 탐색 공간 전체**를 보여주고, 연구자가 직접 골라 시편으로 등록합니다.
- **모든 숫자에 근거**: 판별 규칙의 기준과 문헌 출처, 계산식, 모델 카드, 최근접 학습 조성과의 거리(외삽 여부)를 표시합니다.
- **실험 루프**: 시편 ID → 실험 계획서 → 실측 입력 → 예측 검증까지 이어집니다.
- **톤**: 라이트(paper) 기본 테마, 고정폭 숫자, 단위·신뢰구간 표기, 이모지/AI 연출 제거. 다크 테마 전환 가능.
- AI 챗봇은 제외했습니다(필요 시 문헌 검색형 보조 패널로 재도입 검토).

## 주의

- 예측 모델(`lib/model.ts`)은 **학습된 모델이 아닌 데모용 해석식**입니다. 수치 경향만 그럴듯하게 움직입니다.
- 문헌 데이터(`lib/literature.ts`)는 **가상 데이터**입니다. 실제 사용 전 검증된 문헌으로 교체해야 합니다.
- 원소 물성(`lib/elementData.ts`)은 금속 원소는 참고값, 기체·비금속·방사성·초중원소는 추정치입니다(주기율표에서 점선 테두리).
- ΔHmix 이원계 값은 주요 금속 쌍만 등록되어 있고, 미등록 쌍은 0으로 가정해 불확실도와 점검 항목에 반영합니다.
